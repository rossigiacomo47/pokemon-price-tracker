Ogni volta che inizi · ● Principiante

Aprire Claude Code nell'app

Niente terminale: l'app Claude per computer include già Claude Code. I passaggi sono uguali su PC Windows e Mac.

1Apri la scheda CodeAvvia l'app Claude e fai clic su Code, in alto al centro.
2Scegli la cartellaSeleziona Local, poi Select folder e scegli la cartella pokemon-price-tracker.
3Scegli la modalitàNel selettore accanto al pulsante di invio: Plan per vedere solo il piano, Manual per approvare ogni modifica.
4Incolla il messaggioCopia dalla guida il messaggio del blocco in cui ti trovi e invialo.
Buono a sapersi. La scheda Code richiede un piano Pro o superiore: il Pro basta. Se su Windows compare «Git is required», installa Git for Windows oppure aggiorna l'app. Dal blocco 2 Git servirà comunque: Claude Code ti guida nell'installazione. Ritmo di lavoro

Ogni sessione in tre mosse

Sessioni brevi, un blocco alla volta: non perdi il filo e consumi meno il tuo piano Claude.

Inizio Fai dire a Claude Code a che punto siete. 
Leggi CLAUDE.md e il README. Dimmi a che punto siamo e riprendiamo dal blocco in corso, dal punto in cui ci siamo fermati.
Durante
  • Nei blocchi grandi usa la modalità Plan: Claude propone il piano senza toccare i file. Quando sei d'accordo, passa a Manual.
  • Prima di approvare una modifica, leggi cosa fa.
  • Se un termine non è chiaro, chiedi: «Spiegamelo con un esempio».
Fine Salva e prepara la ripartenza. 
Prima di chiudere: salva il lavoro (anche su GitHub, se è già collegato) e aggiorna il README con cosa abbiamo fatto, cosa manca e il primo passo della prossima sessione.

Da tenere a mente

Cinque regole d'oro

  1. Un blocco alla volta. Si passa al successivo solo con tutte le caselle spuntate.
  2. Prima il piano, poi il codice. Se il piano non ti è chiaro, non dare l'ok.
  3. Chiavi e token solo nei posti sicuri: Secrets di GitHub o Comando Rapido. Mai in chat, mai nei file.
  4. Verifica con i tuoi occhi: controlla sempre le tue carte di controllo e apri 2–3 comparabili sui link.
  5. Chiudi sempre salvando: usa il messaggio di «Fine» a ogni sessione.
